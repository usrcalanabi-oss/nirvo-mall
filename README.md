# NIRVO MALL

An independent luxury-shopping destination under the NIRVO brand.

## Current stage
The first storefront experience is in place: responsive black-and-gold editorial design, department discovery, search interaction, shopping-bag drawer, and launch messaging. Product inventory, customer accounts, order processing, payments, and admin tools are not yet connected. No live purchases are accepted in this preview.

## Run locally
Open `index.html` in a browser, or run a static server from this directory.

## Deploy
Connect this repository to a new Vercel project. It is a static site with no build command and the repository root as the output directory.

## Independence
This project has its own repository and is not integrated with the existing NIRVO company website, its cart, accounts, APIs, or data.
